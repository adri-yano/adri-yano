## ⏱ About Me

I'm a Software Engineering student who designs systems end-to-end — from database schema to deployed API to the UI on top of it — and then stress-tests them to understand what makes them solid.

My work sits across three areas:

- 🏗 **Full-Stack & Backend Engineering** — building production-style apps and REST APIs with clean architecture (Java, Spring Boot, React, Next.js, PostgreSQL)
- ☁ **Cloud, Linux & DevOps** — containerizing and deploying services with Docker, exploring Kubernetes and AWS
- 🔐 **Cybersecurity Fundamentals** — learning the security side of the systems I build, from JWT auth to basic network analysis
